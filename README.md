Ubuntu Autoinstall ISO BuilderThis project is designed to automate the generation of custom Ubuntu Server ISO images that include an autoinstall.yaml file for repeatable, hands-off installations. This initial version is configured for Ubuntu Server 24.04.3.PrerequisitesFor the fastest build time, it is recommended that you first download the official Ubuntu Server 24.04.3 ISO to the root directory of this project.wget [https://releases.ubuntu.com/24.04.3/ubuntu-24.04.3-live-server-amd64.iso](https://releases.ubuntu.com/24.04.3/ubuntu-24.04.3-live-server-amd64.iso)
If you skip this step, the script will automatically check for the file and download it if it's missing. The initial build will just take longer.How to UseTo create your custom ISO, simply run the following commands from the root of the project.1. Build the Docker ImageThis command creates the containerized environment with all the necessary tools to build the ISO. You only need to run this once, or whenever you change the Dockerfile.# To build the docker container
`docker build -t ubuntu-2404-iso-builder .`
2. Generate the Custom ISOThis command runs the container, which executes the script to create your ISO.# To generate an ISO
`docker run --rm -v "$(pwd):/data" -e HOST_UID=$(id -u) -e HOST_GID=$(id -g) ubuntu-2404-iso-builder`
This process will create a new file named ubuntu-24.04.3-autoinstall.iso in the root directory of the project.CustomizationTo customize your build, simply edit the contents of the autoinstall.yaml file and re-run the docker run command. The current autoinstall.yaml is configured to install Kubernetes, Docker, Ansible, and Git.For rapid testing and iteration, you can delete the previously generated ubuntu-24.04.3-autoinstall.iso file and run the docker run command again. The script automatically cleans up all temporary files after each successful build.
